# SpiderSense - Red Spider Mite Detection for Pesticide Control 🌱🕷️

**SpiderSense** is a mobile app that helps farmers detect **red spider mite infestations** on crop leaves in real-time using AI. Snap a photo of a leaf, and the app tells you the **infestation level** and even suggests the **right amount of pesticide** to use! 💡

By using SpiderSense, farmers can reduce pesticide usage by around **30%**, making agriculture more **sustainable** and better for the **environment**. 🌍

### Features
- Real-time **leaf image classification** with AI
- **Mobile-friendly** deep learning model (MobileNetV2 + Flutter)
- Helps promote **sustainable farming**
