
# Red Spider Mite Detection for petiside control - SpiderSense

This project is a mobile application designed to detect red spider mite infestations on crop leaves in real-time using AI-powered image classification.

The app uses a deep learning model based on MobileNetV2, optimized for mobile deployment via Flutter, enabling farmers to quickly identify infestation levels by simply capturing leaf images.

By providing accurate detection and pesticide dosage recommendations, this app aims to reduce pesticide usage by around 30%, promoting sustainable agriculture and minimizing environmental impact.
